📘 Sistema de Controle de Peças — Automação Digital
📌 Descrição
Sistema em Python desenvolvido para o desafio de automação industrial.
Realiza cadastro, inspeção, armazenamento e geração de relatórios.
________________________________________
🚀 Funcionalidades
✔ Cadastrar nova peça
✔ Validar qualidade automaticamente
✔ Listar peças aprovadas e reprovadas
✔ Remover peças cadastradas
✔ Armazenar peças aprovadas em caixas (10 unidades)
✔ Fechar caixas automaticamente
✔ Gerar relatório final consolidado
________________________________________
🧠 Regras de Qualidade
•	Peso entre 95g e 105g
•	Cor azul ou verde
•	Comprimento entre 10cm e 20cm
________________________________________
📂 Como rodar o programa
1.	Instale o Python 3.x
2.	Baixe o repositório
3.	No terminal, execute:
python main.py
________________________________________
📥 Exemplo de Entrada
ID: A45
Peso: 100
Cor: azul
Comprimento: 15
📤 Exemplo de Saída
Peça aprovada e armazenada na caixa 1.
